# VFX Notes — 장면의 안쪽

화이트·웜그레이의 편집 노트 형식으로 구성한 VFX 분석 사이트.

## 구성

- 아카이브: 대표 클립 6개와 전체 80개 기록, 유형·구현 방식 필터, 텍스트/타임코드 검색.
- 상세 기록: 구간 제한 영상 재생, 원본의 시작·중간·끝 프레임, 구도·VFX 관찰·AI 구현 제안·검수·근거 섹션.
- 분석 방법: 관찰·제작 확인·추정의 구분과 범위.
- 기록에 관하여: 자료 출처, 원문 Markdown/CSV/모델 사양 다운로드.

`dist/`는 빌드 없는 HTML/CSS/JS다. `analysis/decision_to_leave_vfx/`의 기존 분석 원문은 보존했다. 분석의 근거 날짜는 2026-10-21이며, 사이트 작성일은 2026-10-22다.

재생 사본은 정적 호스팅의 단일 파일 크기 제한을 고려해 720p로 압축했다. 화면 분석용 스틸은 원본에서 추출한 자료를 별도로 제공한다.
